# Cost Policy

RancangLoka masih bootstrap. Cost efficiency adalah requirement produk.

## Principles

- Complexity juga cost.
- Jangan call model kedua jika tidak perlu.
- Jangan search jika claim tidak membutuhkannya.
- Jangan regenerate artikel penuh untuk error format.
- Lakukan targeted repair.
- Retry hanya bagian yang gagal.
- Tetapkan budget per job.
- Catat biaya per artikel.

## Evidence cost

Default:
- LOW: $0 research/search
- MEDIUM: selective claim evidence
- HIGH: strict evidence
- CURRENT: live research

## Image cost

Hybrid manual + AI.

Suggested:
- Pillar: 1 cover + 2–3 contextual visual bila berguna
- Comparison: 1 cover + 1–2 diagram/context visual
- Problem solver: 1 cover + optional diagram
- Regular evergreen: cover saja atau manual image
- Update/trend: manual/source image + AI jika perlu

Diagram sederhana sebaiknya SVG/HTML generated by code.

## Budget guard

Hermes production harus punya:
- per-job hard cap,
- max retries,
- max evidence/search rounds,
- max image count,
- stop condition.

Never allow open-ended agent loops.
